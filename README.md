## Basic Info

This game was created for the **T3G competition (2nd edition)**.

It was developed in 2022 and was my first larger project made in **Unity**.

Our team achieved **10th place in Poland**.

## Game Info

The game is a simple story-driven experience with quests, enemies that the player must avoid, and a fixed camera system.

It is a relatively simple concept, but still provides some fun gameplay.
